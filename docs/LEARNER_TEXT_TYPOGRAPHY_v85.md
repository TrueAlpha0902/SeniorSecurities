# v85 學員文字排版與全形標點 QA

## 原則

v85 不直接修改證券高業或初階外匯的來源題庫。`formatLearnerText()` 只在畫面呈現時處理排版，答案比對、題目 ID、搜尋索引及稽核雜湊仍使用原始資料。

## 轉換項目

```text
(1) → （1）
,   → ，
;   → ；
:   → ：
?   → ？
!   → ！
%   → ％
/   → ／
&   → ＆
~   → ～
... → ……
--  → ——
```

英文雙引號轉為「」，中文引號內容可轉為『』，英文字尾撇號使用 `’`。

## 保護項目

格式化前會先保護：

- HTTP／HTTPS網址
- Email
- 小數，例如 `3.25`
- 千分位，例如 `1,000`
- Markdown 表格分隔線

公式中的等號、加減乘除符號、希臘字母與上下標不會被重新計算或改寫；斜線及括號只做顯示字形轉換。

## 全量結果

| 題庫 | 題幹 | 選項 | 解析 | 合計 |
|---|---:|---:|---:|---:|
| 證券高業 | 3,526 | 14,104 | 3,526 | 21,156 |
| 初階外匯 | 3,250 | 13,000 | 3,250 | 19,500 |
| **總計** | **6,776** | **27,104** | **6,776** | **40,656** |

`npm run test:learner-text` 已逐欄驗證，不允許未受保護的半形括號、逗號、分號、冒號、問號、驚嘆號、百分號或方括號殘留於學員顯示文字。
