## v91契約鎖定內容

- 全域根節點載入 `theme-v91`。
- 導覽與首頁使用生成手寫資產。
- 證券與外匯作答結果使用生成的「正確／錯誤」圖片。
- 圖像失敗時顯示文字備援。
- 非裝飾圖像保留螢幕閱讀器文字。
- 手機上一題／下一題維持正常文件流及safe-area間距。
- 設定只暴露證券高業與初階外匯兩份考試計畫。
- 考科頁不提供獨立考試計畫編輯器。
- 每個題庫使用一個共同日期、每日時間及備考強度。

## 環境限制

容器的npm套件來源無法完成相依套件安裝，因此完整 `npm run verify` 尚未在此環境完成。Windows更新器會執行完整閘門並於失敗時停止。此限制不影響已完成的來源碼語法、靜態契約與資產驗證，但不能取代正式Production build。
