# v79.4 Cross-page Crop Tools

## 問題

原題目編輯器只能移動整個 crop，或增加寬度／高度。跨頁題目由兩段圖片堆疊時，第一段底部與第二段頂部的白邊無法獨立移除，因此 App 預覽會出現過大的中間空白。

## 解法

- `裁上`：增加 `y` 並等量減少 `height`，保留原本底部。
- `裁下`：只減少 `height`，保留原本頂部。
- `裁左`／`裁右`：同樣以邊界語意調整。
- `接縫兩側各裁`：同時裁掉前段底部與本段頂部。
- `自動壓縮與前段接縫`：載入兩張來源頁面，以 Canvas 掃描文字像素，保留安全 padding 後裁除邊緣白區。
- 所有快速裁切動作可復原，最多保留 30 個狀態。
- 預覽會標示目前正在編輯的段落。

## 使用方式

對跨頁題目選擇「段落 2」，先按「自動壓縮與前段接縫」。若仍需微調，選擇 1 或 5 px 步長，再使用「裁上」或「接縫兩側各裁」。完成後按「儲存工作草稿」。
