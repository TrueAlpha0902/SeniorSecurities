# v68 Upgrade Guide

此版本只修改前端、測試與交接文件，不包含資料庫 migration，也未新增 npm 套件。

套用後執行：

```powershell
npm run verify
```

人工 smoke test：

1. 首頁只看到今日應做題數，點「說明」可查看詳細安排。
2. 導覽列計算機可開啟、關閉，手機版不超出視窗。
3. 解 x 模式可正確解兩個內建範例。
4. 分數按鈕可輸入分子與分母並插入算式。
5. 模擬考頁只有自訂題數與單科選擇，頁面最上方是規則。
6. 模擬考作答顯示經過時間，不倒數、不自動交卷。
7. 全站主色為深藍，沒有鈷藍或裝飾性漸層。
