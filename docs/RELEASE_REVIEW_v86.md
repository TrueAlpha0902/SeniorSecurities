# SeniorSecurities v86 發布前審查

更新日期：2026-07-22  
狀態：來源修改、靜態契約與手機布局驗證完成；尚未部署 Production。

## 1. 版本目的

v86 不增加新題庫，重點是把兩套證照的資訊架構、考試計畫與手機作答流程收斂為同一套產品規則：

1. 證券高業依正式考試結構只顯示三個考科。
2. 證券法規與實務合併為同一考科，不在學員端拆成兩張卡片。
3. 三個證券考科與兩個外匯考科各自保存考試計畫。
4. 只有模擬考顯示計時，一般練習完全不顯示。
5. 手機上一題／下一題位於頁面最底部，不浮動、不遮住選項或解析。
6. 證券與外匯首頁、題目、選項、解析、進度與操作層級採共同設計語言。

## 2. 證券法規與實務合併

學員端正式考科固定為：

- 投資學
- 財務分析
- 證券相關法規與實務

內部來源資料仍保留：

- `securities-trading-regulations`
- `securities-trading-practice`

這兩個來源 bank 只用於來源追蹤、題目 ID、既有作答紀錄與稽核。學員導航使用虛擬整合 bank：

```text
securities-laws-practice
```

整合規則：

- 一張科目卡片
- 一份學習進度
- 一份考試計畫
- 一個章節頁
- 一個每日題量
- 舊法規與實務網址安全導向整合科目
- 作答、錯題、收藏與雲端紀錄仍沿用原題目 ID，不需資料庫 migration

## 3. 分科考試計畫

v86 使用五個正式 scope：

```text
investment
financial-analysis
securities-laws-practice
fx-remittance
fx-trade
```

每一 scope 各自保存：

- 考試日期
- 每日可用時間
- 備考強度
- 每日建議題數

舊版資料遷移：

- 舊的整張證券計畫可作為三個證券考科的 fallback。
- 舊的法規／實務分開計畫會優先保留已有日期的一份，合併至 `securities-laws-practice`。
- 外匯兩科分別遷移，不共用日期。
- 遷移只發生於使用者 scoped localStorage；不刪除答題資料。

## 4. 計時規則

顯示計時器：

- 證券高業模擬考：累計測驗時間
- 初階外匯模擬考：剩餘時間

不顯示計時器：

- 章節練習
- 科目練習
- 全題庫
- 每日練習
- 錯題複習
- 收藏題目
- 外匯逐題
- 外匯隨機練習
- 相似題

一般練習仍可在背景累積總學習時間，用於會員紀錄與排行榜，但不在題目頁顯示或提供暫停按鈕。

## 5. 手機作答流程

兩套題庫的上一題／下一題均位於正常 document flow：

```text
題目
四個選項
作答後解析
上一題／下一題
safe-area 留白
```

具體規則：

- `position: static`
- 不使用 fixed、sticky 或 backdrop overlay
- 360–430px 手機皆為兩個等寬按鈕
- 最後一個選項／解析底部與導覽列之間保留間距
- iPhone safe-area 由頁面底部 padding 處理
- 切換下一題不主動向下捲動
- 手機選項高度至少 62px
- 不出現橫向捲動

## 7. 資料與安全邊界

本版沒有修改：

- 證券高業 3,526 題題幹、選項、答案與解析
- 初階外匯 3,250 題題幹、選項、官方計分與解析

未在本容器完成：

- 真實依賴下的 API semantic typecheck

## 9. 發布建議

1. 先在本機執行 `APPLY_V86.cmd`。
2. 確認所有 Windows 發布閘門通過。
3. 以 390px 寬手機實際登入檢查證券一般練習、證券模擬考、外匯逐題與外匯模擬考。
4. 確認一般練習沒有計時器，模擬考有計時器。
5. 確認法規與實務只出現一次。
6. 再執行 Production 部署。
