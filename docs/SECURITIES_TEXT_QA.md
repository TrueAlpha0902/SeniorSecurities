## App 行為

- 一般練習、模擬測驗、正解練習、相似題目與搜尋結果皆使用文字內容。
- 每題四個選項以完整文字按鈕顯示，不再以掃描圖片中的選項作為主要操作介面。
- 作答後顯示掃描轉錄的解析；模擬測驗仍遵守交卷前不顯示正解、正誤樣式與解析。
- 公式與長文字正常換行；Markdown 表格轉為可橫向捲動的 HTML 表格。
- 學員端不提供原始題圖或原始解析圖入口；掃描檔只供內部稽核與管理工具使用。
- OCR 引擎、信心值、候選文字、裁切座標、檔案路徑與內部稽核狀態不顯示給一般使用者。
- 管理員若日後修改裁切範圍，舊文字會因來源雜湊不一致而失效；學員端將顯示中性提示並停止呈現該欄位，不會回退原圖。
