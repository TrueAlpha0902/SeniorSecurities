# v79.5 裁切專注工作區

## 目的

讓跨頁題目裁切可以在一般桌面單一視窗內完成，不再需要在大量欄位、控制按鈕與底部儲存列之間上下捲動。

## 預設畫面

- 上方：科目、章節、題目與跳題。
- 題目列：題目資訊、正確答案、復原與儲存。
- 快速工具列：題目／解析、段落、步長、自動裁白邊、自動壓縮接縫。
- 左欄：上下移動、裁上／裁下、減高／加高、跨頁接縫。
- 右欄：大型即時預覽，獨立捲動並標示目前段落。

## 進階設定

預設收合，內含圖片路徑、頁碼、X／Y、寬高、原頁尺寸、左右裁切、左右移動、段落新增／移除、重新載入及恢復部署版本。

## 發布功能

題庫發布流程仍完整保留，但改為預設收合，避免干擾日常裁切。

## 驗證

- TypeScript / API TypeScript
- ESLint
- 管理後台契約測試
- PDF crop editor 測試
- 圖片題庫驗證
- Production build / PWA / bundle budget
