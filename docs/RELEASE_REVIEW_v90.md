# SeniorSecurities v90 發布前審查

更新日期：2026-07-23
狀態：來源與更新包準備完成，尚未部署 Vercel。

## 版本目的

v90 將全 App 套用使用者核准的暖白紙張、繁體中文楷體、細線框、手繪 SVG 與低飽和金融色系模板。桌面版與手機版共用同一設計語言，證券高業與初階外匯只以海軍藍／鼠尾草綠區分。

## 已完成

- 全域 AppLayout 改為紙張式左側導覽、精簡工具列與手機導覽。
- 桌面側欄加入圖釘式今日學習目標，顯示完成題數／規劃題數與進度線。
- 證券高業與初階外匯首頁共用相同模板。
- 首頁加入手繪主視覺、整體進度、共同考試日期、今日建議、六項捷徑、考科路徑、數據摘要與考試資訊。
- 初階外匯保留第23至47屆緊湊入口。
- 兩套作答頁共用模板式頂部列、圓形選項代號、收藏星號、斜線狀態、解析紙張與正常文件流底部控制。
- 移除 v88／v89 主題檔與舊主題契約，避免多層主題互相覆寫。
- 新增 v90 模板契約，更新 v86 功能契約以檢查目前主題。

## 未改動

- 證券高業 3,526 題。
- 初階外匯 3,250 題。
- 題目答案與解析。

## 字體界線

專案不封裝或散布字型檔。Windows 優先使用標楷體，macOS／iOS 優先使用 BiauKai／系統楷體，Linux 預覽使用文鼎中楷。字距、行距、尺寸及排版均固定，但不同作業系統的字形輪廓可能略有差異。
