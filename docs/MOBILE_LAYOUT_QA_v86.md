# v86 手機布局 QA

## 目標

- 做題內容優先於導覽與統計。
- 上一題／下一題永不遮住選項或解析。
- 一般練習不顯示計時器。
- 兩套題庫使用相同的題目、進度、答案回饋、解析與底部操作節奏。

## 實作規則

- 題目導覽使用正常頁面流，不使用 fixed／sticky。
- 手機導覽兩欄等寬，最小高度 52px。
- 選項最小高度 62px。
- 題目與解析保持白底；首頁以低彩度色塊建立層級。
- 360–430px 不允許 horizontal overflow。
- 390px 寬度下，證券與外匯答題頁的解析後立即接導覽列。
