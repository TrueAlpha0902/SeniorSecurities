# PDF 圖片題庫審核標準

圖片題庫每次重新匯入、重切或部署前，必須符合以下規則：

1. 題目圖片不可截掉文字頂部、底部或選項。
2. 題號左邊 PDF 原始答案標記必須切掉，只保留題號與題目內容。
3. 跨頁題目必須合併顯示，且所有題目段落使用相同左邊界，避免上下段落錯位。
4. 作答選項只顯示 `(1)`、`(2)`、`(3)`、`(4)`。
5. 作答後正確答案使用綠色邊框，錯誤選擇使用紅色邊框，不使用整片綠色或紅色底。
6. `《解析》` 上方全部屬於題目；解析圖片必須從 `《解析》` 開始。

建議抽查案例：

- `financial-analysis-ch03-pdf-0042`
- `financial-analysis-ch03-pdf-0054`
- `financial-analysis-ch03-pdf-0077`
- `financial-analysis-ch04-pdf-0002`
- `financial-analysis-ch04-pdf-0014`
- `financial-analysis-ch04-pdf-0015`
- `investment-ch01-pdf-0008`
