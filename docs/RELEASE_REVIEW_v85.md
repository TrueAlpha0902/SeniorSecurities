# SeniorSecurities v85 發布前審查

更新日期：2026-07-22  
版本：**v85 — 高精度學習回饋與分題庫設定版**  
狀態：**來源、資料契約、型別、建置與預覽均完成；尚未部署正式網站。**

## 1. 本版目標

v85 聚焦於四個學習體驗問題：

1. 作答後不再重複顯示「答對／答錯、你的答案、正確答案」摘要。
2. 題目、選項及解析使用較舒展的中文排版與全形標點。
3. 相似題只保留人工確認為同考點、且具有可比較差異的配對。
4. 正解模式與資料重設依題庫分開管理，避免跨題庫誤操作。

題庫內容、官方答案、既有解析及會員授權資料均未因本版介面重整而改寫。

## 2. 作答回饋

證券高業與初階外匯已統一為選項層級回饋：

- 正確選項：淡綠底、粗綠框、左側綠色強調線及勾號。
- 使用者選錯的選項：淡紅底、粗紅框、左側紅色強調線及叉號。
- 不再額外顯示「答對了／答錯了」結果卡。
- 不再列出「你的答案／正確答案」文字摘要。
- 解析維持白底中性色，不使用紅綠色大面積背景。
- 手機選項維持至少 68px 的可點擊高度。

## 3. 學員文字排版

新增 `src/lib/learnerText.ts` 作為純顯示層格式化器：

- 半形括號、逗號、分號、冒號、問號、驚嘆號、百分號、斜線等轉為全形。
- 英文雙引號轉為中文直角引號，省略號與破折號統一。
- 題幹、四個選項、解析及表格儲存格共用相同規則。
- URL、Email、小數、千分位數字及 Markdown 表格分隔線會先保護，再進行格式化。
- 原始題庫 JSON 不被覆寫，所有轉換只發生在學員畫面。
- 題幹、選項及解析行高同步提高，改善手機閱讀密度。

全量契約已檢查 **40,656 個學員可見欄位**。

## 4. 相似題

舊版以較寬鬆的自動相似度為主；v85 改為人工核對的高精度配對：

- 只保留同一題庫、同一章節的題目。
- 題幹與四個選項均需完整檢視。
- 「下列何者正確」等通用問句不能單獨構成相似證據。
- 相反目標、不同法規主題或只有圖片版面相似者排除。
- 完全相同且沒有可比較條件差異的重複題排除。
- 每題最多屬於一組，避免同一題被反覆配對。
- 每組固定兩題，顯示共同考點與真正改變答案的條件。

最終收錄：**19 組、38 題**。完整逐組紀錄見 `docs/SIMILAR_QUESTION_REVIEW_v85.md` 與 `docs/similar-question-groups-audit.json`。

## 5. 分題庫正解模式

正解模式改為六個獨立 scope，全部預設關閉：

- 投資學
- 財務分析
- 證券交易相關法規
- 證券交易相關實務
- 初階外匯／國外匯兌業務
- 初階外匯／進出口外匯業務

開啟其中一個題庫不影響其他題庫；正式模擬考仍維持伺服器延後批改，不會因正解模式提前揭露答案。

## 6. 資料重設

設定介面改為三階段：

1. 選擇證券高業、初階外匯或全部題庫。
2. 選擇清空錯題清單、重新開始進度或刪除全部學習資料。
3. 顯示實際影響數量，勾選理解聲明後再進行最後確認。

三個層級：

| 層級 | 清除內容 | 保留內容 |
|---|---|---|
| 清空錯題清單 | 待複習錯題標記 | 歷史作答、正確率、收藏及進度 |
| 重新開始進度 | 作答、錯題、章節進度及測驗紀錄 | 收藏題目 |
| 刪除全部學習資料 | 作答、錯題、收藏、進度及測驗紀錄 | 無 |

初階外匯錯題清單已從歷史答案中分離，清空錯題不再連帶刪除正確率統計。

## 7. 首頁工具

證券高業首頁的練習工具移除：

- 今日錯題

搜尋仍可由全域導覽進入；錯題集中於「錯題複習」，避免重複入口。
