# v90 紙張草稿模板規格

## 視覺基準

v90 依使用者核准的「學習與考試管理介面設計」模板實作。設計重點不是一般玻璃或 SaaS 儀表板，而是具有紙張、楷體與細線稿質感的金融證照學習桌面。

## 全域規則

- 頁面背景：暖米灰紙張色。
- 內容底色：暖白，不使用高飽和漸層。
- 框線：1px 中性灰細線，圓角 5～13px。
- 陰影：只保留非常輕的紙張浮起感。
- 字體：依序使用 `Klee One`、文鼎中楷、標楷體、BiauKai、KaiTi 與 Noto Serif CJK TC。
- 數字：日期、題數與百分比使用等寬數字，維持對齊。
- 插圖：以 React 內嵌 SVG 建立手繪 K 線、地球、匯兌箭頭、圖釘便條、折線圖及考試文件圖。
- 不封裝或散布字型檔。

## 桌面結構

1. 左側紙張式導覽。
2. 中性品牌「金融證照／學習中心」。
3. 題庫功能、工具、學習分析、帳號與設定分組。
4. 底部圖釘式今日學習目標。
5. 右側內容區：題庫標題、手繪主視覺、三張概況卡、學習捷徑、考科路徑、數據摘要及考試資訊。

## 行動版結構

- 非作答頁：精簡頂部品牌與五項底部導覽。
- 作答頁：移除全域底部導覽，只保留題目內的上一題、題目列表、下一題。
- 題目選項採圓形代號、紙張留白與細線框。
- 正確選項採低飽和藍／綠斜線底紋；錯誤選項採低飽和紅斜線底紋。
- 解析採淡綠紙張底紋。

## 題庫差異

- 證券高業：海軍藍線稿、K 線與上升走勢。
- 初階外匯：鼠尾草綠線稿、地球、匯兌箭頭與貨幣符號。
- 功能位置、排版層級、卡片尺寸與作答流程保持一致。

## 功能約束

- 證券高業維持三個正式考科。
- 初階外匯維持兩科與第23至47屆入口。
- 每張證照只有一份共同考試日期。
- 一般練習不顯示計時器；模擬考才顯示計時器。
- 題目、答案、解析、會員權限及學習紀錄不因主題修改而變更。
