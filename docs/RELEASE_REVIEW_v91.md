# SeniorSecurities v91 發布前審查

更新日期：2026-07-24  
版本：v91 — 圖像手寫介面與題庫級考試計畫

## 1. 產品範圍

v91 延續 v90 的紙張草稿資訊架構，但把固定介面標籤、主要功能圖示與裝飾插圖改為生成圖像資產。題幹、選項、解析、日期、數字與帳號資料不轉為圖片。

題庫內容保持：

- 證券高業：3,526題，學員端三考科。
- 初階外匯：第23至47屆，共3,250題，兩科。
- 合計：6,776題；本次不改寫任何題目、答案或解析。

## 2. 考試計畫模型

正式可編輯計畫只有兩份：

1. `senior-securities`：投資學、財務分析、證券相關法規與實務共用。
2. `junior-foreign-exchange`：國外匯兌業務、進出口外匯業務共用。

每份包含共同考試日期、每日可用時間及備考強度。每日題量仍會按考科剩餘題數、錯題與複習需求分配，但考科頁不再出現獨立計畫編輯器。

舊 v2／v3 分科設定僅作遷移來源；新寫入使用 `quizpwa:study-plan:v4:<examId>`。

## 3. 圖像資產與可及性

- PNG資產：94個。
- 總容量：約6.40 MiB。
- 單檔上限：650 KiB契約。
- PWA precache glob不包含PNG，資產按需下載，不會把全部手寫素材強制放入離線快取。
- 圖片載入失敗時顯示文字備援。
- 非裝飾資產保留 `sr-only` 可讀文字。
- 固定介面標籤才圖像化；學習內容維持語意文字。
