# SeniorSecurities v85.1 發布前審查

日期：2026-07-22

## 變更摘要

v85.1 僅處理兩項學員體驗調整：

1. 正解模式由六個題庫開關收斂為一個全域開關。
2. 作答結果恢復整張選項全紅／全綠的高辨識回饋。

題目、答案、解析、題庫權限、模擬考伺服器批改與 Supabase schema 均未變更。

## 正解模式

- 設定頁只保留一個「正解模式」開關。
- 開關位於「一般」，證券高業與初階外匯共用。
- 預設關閉。
- 開啟後只影響一般練習；正式模擬考仍延後批改，不會提前顯示答案。
- 升級時會將舊的分證照／分題庫開關清為關閉，避免沿用舊設定意外揭露答案。
- 設定頁移除沒有其他設定內容的「初階外匯」分頁，手機只保留三個設定分類。

## 作答回饋

- 答對選項：整張深綠底、白字、白色勾號。
- 答錯選項：整張深紅底、白字、白色叉號。
- 選錯時同步顯示正確選項的全綠狀態。
- 證券高業、初階外匯與相似題使用同一套狀態規則。
- 沒有恢復重複的「你的答案／正確答案」摘要卡。
- `prefers-reduced-motion` 使用者不執行結果動畫。

## 資料與部署邊界

- Vercel Functions：8／12。
- Production 不公開來源掃描或付費章節 shards。
- 無新增 migration。
- 此更新包不會自動部署 Vercel，也不會修改 Supabase。

## 發布建議

套用更新後，先在本機登入測試帳號，分別驗證：

1. 全域正解模式預設為關閉。
2. 開啟後證券與外匯一般練習都直接顯示答案。
3. 模擬考交卷前仍不顯示答案。
4. 答錯時錯誤選項全紅、正確選項全綠。
5. 關閉正解模式後重新載入仍保持關閉。
