TrueAlpha 啟用碼產生器

使用方式：
1. 請確認 C:\Users\speci\Documents\SeniorSecurities\.env.local 內有：
   VITE_SUPABASE_URL=...
   SUPABASE_SERVICE_ROLE_KEY=...

2. 雙擊 ActivationCodeGenerator.exe。
   如果 exe 無法產生，雙擊 ActivationCodeGenerator.cmd 也可以。

3. 「專案資料夾」請指向 SeniorSecurities 專案根目錄：
   C:\Users\speci\Documents\SeniorSecurities
   不要指向：
   C:\Users\speci\Documents\SeniorSecurities\desktop

4. 自訂啟用碼可留空，留空會自動產生。

5. 產生成功後，啟用碼會自動複製到剪貼簿，Supabase 也會立刻認得這組碼。
